# 1.4.8 세이브 코드 추출 수정

이전 1.4.7은 세이브 코드 제목에서 상위 영역으로 계속 넓혀 일반 텍스트를 코드 후보로 만들 수 있었습니다. 또한 잘못 읽은 결과가 정상/복구 기록으로 저장되면 같은 인증번호에서 그대로 재사용되었습니다.

## 결과의 범위

제목의 뒤쪽 형제 영역만 읽고 문서 전체나 메뉴로 올라가지 않습니다. `code`, `pre`, `output`, 읽기 전용 입력칸, 명시적인 코드 서식의 본문만 직접 읽습니다. 단순히 영문과 숫자로만 된 일반 문단은 코드라는 근거로 쓰지 않습니다. 링크 자신과 링크를 포함한 요소, 메뉴, 표, 인증번호 입력폼, 숨겨진 값은 제외합니다.

복사 방식은 같은 결과 영역의 복사 버튼이 하나로 특정될 때만 사용합니다. 링크/주소/공유 버튼은 누르지 않습니다. 페이지 복사 처리에 전달된 값만 임시로 받으며 운영체제 클립보드의 내용을 읽거나 변경하지 않습니다. 웹주소, 맵 주소 부분, 현재 인증번호를 결과값으로 받으면 성공 처리하지 않습니다.

제출 직후 성공 문구가 떠도 본문이 이전 값이면 반환하지 않습니다. 새 값이 나타나기를 기다리고 필요하면 GET을 한 번 새로 읽습니다. 중복 POST는 하지 않습니다.

## 기존 기록

기록 DB에 추출기 버전 표시를 추가합니다. 기존 행과 저장 문자열을 삭제하지 않습니다. 1.4.7 이전 결과는 UI에서 '사이트에서 다시 확인'으로 표시하며 F8 입력용 코드로 사용하지 않습니다. 행 선택 또는 같은 인증번호 사진 처리 시 현재 로그인 계정의 최근 코드를 GET으로 다시 읽습니다. 새 발급과 구분해 '사이트에 보관된 세이브 코드'로 표시합니다.

사이트가 결과 코드를 제공하지 않는 경우 완료로 표시하지 않고 결과 확인 상태로 둡니다. 계정과 닉네임은 사이트에서 로그인한 계정 기준입니다.

## 검증

실제 Qt 내장 브라우저와 로컬 HTTP 서버를 사용해 자동 제출→코드 발급→앱 표시를 검사합니다. 링크, 일반 영문 문구, 범위를 벗어난 복사 버튼, 링크 복사 버튼, 복수 결과, 인증번호 입력칸을 제외하는 검사와 기존 DB 마이그레이션, 잘못 저장한 이전 결과의 GET 재확인, 늦게 갱신되는 코드 본문을 검사합니다.

실제 계정으로 SCRMaps에 인증번호를 제출하지 않았습니다. 공개 페이지 확인은 로그인 전 구조에 한정됩니다. 실제 Windows 설치/실행과 서명은 검증 범위 밖입니다. 개인 사진과 코드·로그인 정보는 배포 소스에 포함하지 않습니다.
