1.4.9 — 사이트의 묶음 세이브 코드 표시 지원

- SCRMaps 전용 .hud-code / .hud-code-group 표시 읽기.
- 표시용 공백·하이픈을 제거한 코드만 앱·기록·F8 입력에 전달.
- DOM·읽기 전용 입력칸·코드 복사 결과에 같은 구분자 처리 적용.
- 링크와 웹주소, 맵 주소 부분, 인증번호 제외 유지.
- 인증번호 OCR 검증은 구분자를 허용하도록 바꾸지 않음.
- 이전 실패 기록의 선택 시 사이트의 최근 코드를 GET으로 재확인.

제공된 화면과 같은 구조를 재현한 로컬 Qt/HTTP 검사를 수행했습니다.
실제 계정의 코드 발급과 Windows 실기 실행은 검증하지 않았습니다.

1.4.8 — 링크 오인과 이전 결과 재사용 수정

- 세이브 코드 제목 아래 결과 영역만 읽고 링크·메뉴·일반 텍스트는 후보에서 제외.
- 결과 영역 안의 코드 복사 버튼만 사용하며 링크/주소 복사 버튼은 제외.
- 웹주소·맵 주소 부분·인증번호를 결과 코드로 저장하지 않도록 최종 검증.
- 이전 추출기의 저장값은 기록을 남긴 채 사이트에서 GET으로 다시 확인.
- 성공 메시지만 먼저 나타나는 경우 이전 코드를 반환하지 않고 새 본문을 기다림.
- 확인 버튼 없는 빠른 자동 제출과 중복 POST 방지 유지.

로컬 Qt/HTTP 자동 제출·결과 표시·기록 재확인 검사를 수행했습니다.
실제 SCRMaps 계정의 코드 발급과 Windows 설치/실행은 검증하지 않았습니다.

1.4.7 — 사진 인식 후 바로 제출하고, 발급 결과를 앱에 표시합니다.

- 기본 설정에서 OCR 확인 버튼 없이 한 번 제출.
- 반복 OCR 검사와 전체 페이지 로딩 대기 감소.
- 텍스트·읽기 전용 입력칸·분할 글자·복사 버튼의 발급 코드 읽기.
- CR2 /board 등록 경로와 영문 대소문자 주소 처리.
- 발급 성공 후 GET 갱신, 이전 미표시 코드의 읽기 복구. 중복 POST 방지.

로컬 Qt/HTTP와 실제 OCR 모델로 검사했습니다. 실제 SCRMaps 계정의 발급 및
Windows 실기 실행·배포 서명은 별도 검증이 필요합니다.
