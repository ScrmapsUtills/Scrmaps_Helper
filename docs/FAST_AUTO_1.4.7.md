# 1.4.7 바로 제출과 발급 결과 표시

## 기본 흐름

로그인과 닉네임 설정을 마친 뒤 자동 저장을 시작합니다. 사진에서 인증번호와 맵을 읽으면 확인 버튼 없이 즉시 한 번 제출하고, 발급된 세이브 코드를 앱의 코드 칸에 넣습니다. 기존 설정은 처음 업데이트할 때 바로 제출이 켜지도록 전환합니다. 설정에서 직접 끄면 수동 확인 모드를 사용할 수 있습니다.

사진에서 번호나 맵을 읽지 못한 경우, 선택한 맵과 사진의 맵이 다른 경우에는 임의로 제출하지 않습니다. 사이트가 거절한 번호나 전송 결과가 불확실한 POST를 반복해서 보내지 않습니다.

## 속도 변경

- 빠른 OCR은 녹색 명암을 보존한 영상과 글꼴 비율 보정 결과를 비교합니다. 이 둘이 맞지 않을 때만 추가 전처리를 실행합니다. 자동 모드에서는 번호를 여러 부분으로 잘라 검사하는 느린 절차를 생략합니다.
- 앱 시작 때 모델을 미리 준비합니다. OCR과 사이트 처리 소요 시간을 로그에 나눠 표시합니다.
- 사용할 수 있는 입력창이 이미 열려 있으면 페이지를 재사용합니다. 이동할 때는 새 문서의 입력창을 기다리며 광고·이미지·글꼴을 포함한 전체 loadFinished를 기다리지 않습니다.
- React 입력값과 버튼 활성 상태를 실제로 확인해 제출하므로 고정된 200ms 대기를 제거했습니다. 결과가 나오면 즉시 읽습니다.
- 로그인 완료 뒤 대기 작업 재개까지 넣었던 2초 대기를 제거했습니다.

제공된 25자리 화면을 같은 모델로 세 번 비교했을 때 상세 모드는 약 0.87~1.01초, 빠른 모드는 약 0.31~0.34초였습니다. 세 경우 모두 같은 번호를 읽었습니다. 이 수치는 제작 환경의 OCR 처리만 측정한 것으로, PC 성능과 실제 사이트 응답에 따라 전체 시간은 달라집니다.

## 발급됐는데 코드 칸이 비어 있던 문제

이전 코드는 특정 문구 아래 두 단계의 텍스트만 읽었고, 결과 입력칸의 value나 깊이 중첩된 카드·분할 글자를 놓칠 수 있었습니다. 이제 결과 문구로 범위를 한정한 뒤 code/pre/output, 읽기 전용 input/textarea, 분할된 글자를 읽습니다. DOM에서 읽을 수 없으면 해당 결과 카드의 복사 버튼에 전달되는 코드만 임시로 받아옵니다. 운영체제 클립보드의 기존 내용을 읽거나 덮어쓰지 않습니다.

일치하는 제출 요청을 확인한 뒤 새 결과 또는 성공 상태가 보여야 코드로 반환합니다. 버튼이 아직 처리 중일 때는 이전 코드를 반환하지 않습니다. 성공 표시 뒤 결과 카드가 갱신되지 않는 경우에는 GET 새로고침을 한 번 수행하고, POST를 다시 보내지 않습니다.

공개 사이트를 확인한 결과 CR2의 코드 등록 화면은 `/cr2/board`였습니다. 이 하위 페이지로 이동하는 흐름을 지원하고, 영문 맵 이름을 소문자 주소로 정규화합니다. 다른 호스트로 인증번호를 보내지 않습니다.

사이트가 '이미 기록된 같은 코드'라고 응답하면 추가 POST 없이 보관된 코드를 읽습니다.

이전 기록이 '결과 확인' 또는 '처리 확인'으로 남아 있으면 자동 모드에서 사이트에 보관된 최근 코드를 읽어 표시합니다. 이 경우 제목을 '사이트에 보관된 세이브 코드'로 표시하며, 새로운 인증번호로 다시 발급했다는 뜻은 아닙니다. 로그인해야 읽을 수 있으면 로그인 완료 뒤 읽기만 재개합니다.

## 검증 범위

실제 Qt 브라우저와 로컬 HTTP 서버로 자동 제출 → 발급 → 앱 코드 칸 표시를 검사했습니다. 읽기 전용 결과, 복사 버튼만 제공되는 결과, 중첩된 결과 카드와 분할 글자, 등록 하위 페이지, 늦게 로딩되는 이미지, GET 복구, 이전 미표시 기록 복구, 서버 오류와 중복 제출 방지 등을 검사했습니다.

제공된 실제 게임 사진과 합성 이미지에 실제 OCR 모델을 실행했습니다. 개인 사진과 실제 인증번호는 소스·Setup에 포함하지 않습니다.

실제 SCRMaps 계정으로 발급 요청을 보낸 검사는 수행하지 않았습니다. Windows 설치·실행 실기와 코드 서명도 별도 확인이 필요합니다. 공개 페이지와 클라이언트 파일은 구조 확인에만 사용했으며 배포 소스에 복제하지 않았습니다.

## 설치와 소스

기존 Helper를 완전히 종료하고 `SCRMapsHelper_Setup_1.4.7.exe`를 실행합니다. OCR·브라우저·Python 런타임이 포함됩니다. 로그인 프로필과 세이브 기록은 기존 사용자 데이터 폴더를 계속 사용합니다.

소스 ZIP은 압축을 풀어 기존 저장소 소스에 반영합니다. `.github/workflows`도 포함합니다. 공식 태그 예시는 `v1.4.7`이며 Windows Setup과 Mac DMG 빌드 경로를 유지했습니다. 이번 전달물은 Windows Setup입니다.
